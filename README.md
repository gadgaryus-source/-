# 트랙 타이머 (안드로이드 앱)

웹 버전과 같은 화면이지만, 신호음과 "한 바퀴" 음성을 **알람 볼륨**으로 냅니다.
휴대폰 볼륨 버튼과 음악 앱은 음악 소리만 바꾸고, 타이머 소리는 알람 볼륨과 앱 안의 "타이머 볼륨"으로 조절합니다.

- 실행 중에는 화면이 꺼지지 않고, 잠금화면 위에도 타이머가 그대로 보입니다.
- 뒤로가기 버튼을 누르면 앱이 닫히지 않고 홈 화면으로 나갑니다.

## APK 만드는 방법 (PC 설치 없이, GitHub 이용)

1. github.com 에 로그인하고 새 저장소(New repository)를 만듭니다. 이름 예: `track-timer`
2. 저장소 화면에서 **Add file → Upload files** 를 누르고, 이 폴더 안의 내용을 통째로 끌어다 놓습니다.
   (`.github` 폴더가 꼭 같이 올라가야 합니다. 안 보이면 숨김 파일 보기를 켜세요.)
3. **Commit changes** 를 누르면 자동으로 빌드가 시작됩니다.
4. 저장소 위쪽 **Actions** 탭 → 맨 위 "Build APK" 실행 → 초록 체크가 뜨면 아래 **Artifacts** 에서 `track-timer-apk` 를 받습니다.
5. 받은 zip 안의 `app-debug.apk` 를 휴대폰으로 옮겨 실행합니다. "출처를 알 수 없는 앱 설치"를 허용해야 설치됩니다.

## Android Studio로 만드는 방법

이 폴더를 Android Studio에서 열고 **Build → Build APK(s)** 를 누르면 됩니다.
